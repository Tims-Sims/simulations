How to Use the PBR Checkpoint Simulator

Welcome, Systems Analyst! In this simulation, you will operate and trace an automated algorithm controlling a Priority Bus Route (PBR) barrier checkpoint in Trinidad and Tobago.

  • Phase 1 — Configure the Algorithm: The algorithm configuration starts randomized! Select the condition for the decision diamond and assign the YES and NO branches to the appropriate outcome boxes.
  • Phase 2 — Run & Observe Traffic: Press Run PBR Checkpoint. 10 animated maxi-taxis, PTSC buses, police cruisers, and private cars approach the RFID scanner.
  • Automated Selection Tracing: Watch the glowing execution token flow automatically through the decision diamond, evaluate the condition, and illuminate the active branch.
  • Faulty Logic Feedback: If your branches are wired backwards, the computer faithfully follows your bad instructions! You will see the logic failure happen in real time and can click Repair Flowchart Logic to fix the system!
